# README checklist

Based on Cornell University's "Guide to writing 'readme' style metadata"
(https://data.research.cornell.edu/data-management/sharing/readme).
Elements marked MINIMUM are what Cornell identifies as the minimum content for reuse.
The final section adds items relevant to Canadian Tri-Agency deposits.

## General information
- g1 title: title of the dataset (MINIMUM)
- g2 creators_contact: names, institutions and email of the principal investigator / people responsible for the data, co-investigators, and a contact person for questions (MINIMUM)
- g3 collection_dates: date or date range when the data was collected (MINIMUM)
- g4 geographic_location: where the data was collected
- g5 keywords: keywords describing the topic
- g6 language: language(s) of the data and documentation
- g7 funding: funding sources that supported the work

## Data and file overview
- f1 file_descriptions: every file listed with a short description of what it contains (MINIMUM)
- f2 file_formats: file formats, where not obvious from the file name
- f3 file_relationships: how files relate to each other, or the folder structure
- f4 file_creation_dates: when the files were created (MINIMUM)
- f5 versions: dates and nature of any updates or versions
- f6 related_data: related data collected but not included in this dataset

## Sharing and access information
- s1 license: license or restrictions on the data (MINIMUM)
- s2 related_publications: links to publications that use or cite the data
- s3 other_locations: other places the data can be found
- s4 recommended_citation: how to cite the dataset

## Methodological information
- m1 collection_methods: how the data was collected or generated (MINIMUM)
- m2 processing_methods: how the data was processed, cleaned or transformed (MINIMUM)
- m3 software_instruments: software or instruments needed to understand the data, with versions (MINIMUM)
- m4 standards_calibration: standards or calibration information, if relevant
- m5 quality_assurance: quality-assurance procedures performed
- m6 quality_codes: definitions of codes used to mark questionable or low-quality values
- m7 people_involved: people involved in collection, processing, analysis or submission

## Data-specific information
- d1 counts: number of variables and number of rows/cases
- d2 variable_list: every variable listed with its full name and definition (MINIMUM)
- d3 units: units of measurement (MINIMUM)
- d4 missing_data_codes: what codes or symbols mean missing data (MINIMUM)
- d5 abbreviations: specialized formats or abbreviations explained

## Canadian context (additions, not from Cornell)
- c1 human_participants: if people were involved, how identities were protected and what participants consented to regarding sharing
- c2 indigenous_data: if Indigenous communities, lands or knowledge are involved, how community rights and data governance were addressed (e.g. CARE, OCAP)
